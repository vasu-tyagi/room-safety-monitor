# Demo Videos

`example_fall.mp4` is a single clip from the Le2i Fall Detection Dataset, used here for technical demonstration purposes only.

Original dataset: https://www.kaggle.com/datasets/tuyenldvn/falldataset-imvia

Citation: I. Charfi, J. Mitéran, J. Dubois, M. Atri, R. Tourki, "Optimised spatio-temporal descriptors for real-time fall detection: comparison of SVM and Adaboost based classification", Journal of Electronic Imaging (JEI), Vol.22. Issue.4, pp.17, October 2013.

For full dataset access for evaluation reproduction, download from the link above.
